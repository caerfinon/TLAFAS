Yes — you can place a KK group “in orbit” by manually setting the group’s reference latitude/longitude and the absolute offset.

This repo’s placement code does exactly that:

it computes the group position from the reference LAT/LON
then applies the absolute offset as the actual altitude above the body
In practical terms, do this:

Pick the reference LAT/LON for the point you want the group to be centered over.
Enable the absolute-offset behavior.
Set the absolute offset to the altitude you want above the planet’s surface (for example, 200000 for ~200 km).
Save the group.
Conceptually, that gives you a static placement “in orbit” at that lat/lon and altitude. It is not a dynamically simulated orbiting craft; it is a fixed KK placement at an orbital altitude relative to the planet. So the trick is: set LAT/LON to the desired orbital longitude/latitude anchor and set absolute offset to the orbital height.

The code also shows the same pattern in the editor’s “snap to surface” logic:

it reads the surface height at the chosen LAT/LON
then sets the absolute offset to the desired altitude above the surface
So the manual method is:

LAT/LON = reference point on the planet
absolute offset = altitude above the planet surface
use absolute mode enabled

That is the KK equivalent of “placing a group in orbit by hand.”
